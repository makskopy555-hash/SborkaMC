# VexWorld Bot

Telegram-бот для сервера VexWorld:
- приветствие + проверка подписки на канал `@VexWorld1`;
- магазин сборок: подписка на 30 дней за Telegram Stars;
- после оплаты бот сам создаёт персональную ссылку в приватный канал со сборками;
- бот сам "выгоняет" пользователя из канала, когда подписка закончилась;
- кнопка "Тех. поддержка" — пока заглушка про технический перерыв.

## 1. Создай бота в BotFather

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Получишь токен вида `123456:ABC-DEF...` — он понадобится как `BOT_TOKEN`.
3. У этого же бота в BotFather можешь задать аватарку/описание — необязательно.

## 2. Создай приватный канал со сборками

У тебя уже есть канал по ссылке `https://t.me/+1yLEiCvxGIVjNjQ6` — ок, используем его.

1. Зайди в настройки канала → **Администраторы** → добавь туда своего бота.
2. Боту обязательно нужны права **"Приглашать пользователей по ссылке"** (Invite Users via Link) и **"Блокировка пользователей"** (Ban Users) — без этого он не сможет выдавать/отбирать доступ.

## 3. Узнай числовой ID приватного канала

Код работает с числовым ID канала (например `-1001234567890`), а не со ссылкой-приглашением.

Проще всего так:
1. Установи зависимости локально: `pip install -r requirements.txt`
2. Создай файл `.env`-переменные или временно впиши токен прямо в `config.py` (потом верни обратно).
3. Запусти: `python get_channel_id.py`
4. Напиши любое сообщение в приватный канал — в консоли появится `Channel ID: -100...`
5. Это число — твой `SHOP_CHANNEL_ID`.

Либо воспользуйся любым ботом-утилитой вроде `@userinfobot`, переслав ему сообщение из канала.

## 5. Разверни на Railway

1. Зайди на [railway.app](https://railway.app), **New Project → Deploy from GitHub repo**.
2. Выбери свой репозиторий `vexworld-bot`.
3. Railway сам увидит `Procfile` и `requirements.txt` и предложит запустить `worker: python bot.py`.
   - Если не подхватит сам — в настройках сервиса (**Settings → Deploy**) укажи **Start Command**: `python bot.py`
4. Перейди в **Variables** и добавь переменные окружения:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `CHANNEL_USERNAME` | `@VexWorld1` |
| `SHOP_CHANNEL_ID` | число, которое узнал на шаге 3 (например `-1001234567890`) |
| `PRICE_STARS` | `50` |
| `SUB_DAYS` | `30` |
| `SUPPORT_CONTACT` | твой юзернейм для связи, например `@vexworld_support` |

5. Нажми **Deploy**. В логах должно появиться `Бот запущен, начинаю polling...`

## 6. Проверка

1. Напиши своему боту `/start`.
2. Подпишись на `@VexWorld1`, нажми "Я подписался".
3. Зайди в "Магазин сборок" → "Купить за 50 ⭐".
4. Оплати звёздами (в тестовом режиме Stars можно оплатить тестовыми звёздами через Telegram, если бот не публичный — см. документацию Telegram Stars).
5. Должна прийти персональная ссылка на приватный канал.

## Важные нюансы

- **Один платёж = один человек.** Ссылка-приглашение одноразовая (`member_limit=1`) и живёт 24 часа на вступление — после этого её нельзя будет использовать, даже если подписка ещё активна. Если пользователь не успел вступить за 24ч после оплаты — нужно обращаться в поддержку (это можно донастроить).
- **Продление:** если пользователь покупает подписку повторно, пока старая ещё активна — новые 30 дней добавляются к текущему сроку, а не затирают его.
- **Удаление из канала** происходит автоматически раз в 30 минут (планировщик в `bot.py`, `check_expired_subscriptions`) — можно поменять частоту проверки.
- **Хранилище:** используется SQLite-файл `vexworld.db` прямо в контейнере Railway. Это ок для старта, но **при каждом новом деплое на бесплатном плане Railway файловая система может пересоздаваться**, и база обнулится. Если это критично — потом можно перейти на Railway PostgreSQL (бесплатный тариф тоже есть) или подключить Railway Volume для постоянного хранения SQLite-файла.
